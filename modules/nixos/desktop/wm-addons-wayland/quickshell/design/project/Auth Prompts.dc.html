Rule syntax differs between Hyprland releases — adapt to yours. pinentry-gnome3 hands the prompt to gcr's system prompter, so theming gcr-prompter covers GPG too. GTK file: ~/.config/gtk-4.0/gtk.css (or gtk-3.0, depending on the build — check with ldd).
Hard to replicate — flagged
warningLayout is not themeable. Badge, details box, keycaps in buttons, requester strip and phrase chip need source patches (GTK: gcr/seahorse UI files; QML: hyprpolkitagent). CSS/palette alone gets colors, radii, fonts and field/button states.
warninghyprpolkitagent is Qt Quick — QSS is ignored. Use palette roles (qt6ct / Hyprland Qt style config); QSS column applies only to Qt Widgets tools.
warningShake: trivial in QML (NumberAnimation on x). Not reachable through GTK CSS — needs code; fallback is the static red ring + error row, which already carry the state.
warning“Accept once” — ssh askpass only returns yes/no, and yes writes known_hosts. A one-time accept needs a wrapper (e.g. temporary UserKnownHostsFile); otherwise ship Reject / Accept.
warningSecret access request — stock gnome-keyring has no per-app access prompt. This variant fits a broker that has one (e.g. KeePassXC's Secret Service “confirm access”).
check_circlePlain-widget safe: spinner (GtkSpinner / BusyIndicator), countdown (2px progress bar), strength meter (level bar), combo box, checkbox — use the native widgets.
Keyboard & focus
Initial focus: the field (identity picker first only if it changed). Tab order: picker → field → eye → checkbox → secondary → risky → primary. ↵ = primary from anywhere except the risky button; Esc = cancel. “Always …” never gets initial focus or Enter.
State timing
Verifying: spinner after 150ms (no flicker), field + checkbox disabled, Cancel stays live. Error: clear, refocus, shake, row. Success: green check badge + row, close after 400ms. Timeout: 30s bar drains linearly, text from 0:30.
Contrast
Stock Latte lavender #7287fd is ≈2.9:1 on base — kept for the window border; primary fill, focus and checks use #3f53d9 (≈5.3:1). Field edges use overlay tones for ≥3:1. Yellow is never used for text.
Fingerprint hintpolkit · polkit-multi only — gpg, ssh-key, ssh-host, keyring, keyring-new, secret never show it · tiles 10a–10l
Placement — own row above the field
The hint is a body row after the message / details / identity and 12px above the field, not a field adornment. The field's trailing slot already holds the eye; PAM strings run to ~60 characters and need a full line; and keeping the finger channel above the field leaves everything below it (error, caps lock, success, timeout rows) to the password. Reading order matches the copy: “touch the reader or enter your password”, then the field.
Spacing — reserved, no jumps
Row min-height 32 (two 16px lines), content centred, glyph 16 + gap 8, text Inter 12/16, clamped at 2 lines. It sits in the 12px body stack, so the dialog is exactly 44px taller than 10a whenever a reader + prints exist — and that height never changes between states. Off keeps the row (muted) for the life of the dialog instead of collapsing.
Accessibility
role=status + aria-live=polite (AT-SPI live region in QML); glyph aria-hidden, every state is its own sentence. Color is redundant: idle/scan/miss/off differ in words, matched also swaps the glyph. Reduced motion: no pulse, no pop, no shake — the text change carries it. The field keeps focus throughout; typing never waits on the reader.
