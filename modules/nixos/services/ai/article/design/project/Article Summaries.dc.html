Design notes

Article summaries — reader

Every frame below is a live Pandoc-shaped page styled only by summaries.css. Scroll inside any frame to try the sticky day headers. Source pages: index, summary, empty.

Palette kept. Catppuccin Latte/Mocha via light-dark(), one token set. Latte blue (4.3:1) is deepened to #1758d8 (5.4:1) for text links; Mocha blue is untouched.
Reading type. Source Serif 4 at 17–19px, 1.65 leading, 68ch. IBM Plex Sans for meta and controls only; JetBrains Mono for code and domains. Charter/Noto/Georgia fallbacks.
Index. Sticky day headers with counts; ≥1024px they move to a sticky left column. Whole row is clickable; visited titles dim slightly. Empty state is pure CSS.
Pandoc title block. Set title: "[All summaries](index.html)" — Pandoc keeps the link, CSS turns it into a “← All summaries” breadcrumb.
Markup additions (3). {count="5"} on each day heading; [zed.dev]{.source} and [Author]{.author} spans on items. Without them it still works, just less refined.
Copy. The y hint is drawn by CSS inside the button and hidden on touch screens. Add aria-live="polite" to .copy-status.
