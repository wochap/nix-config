# Soularr

Bridge between Lidarr and slskd. Every `interval` seconds (default 300) it reads Lidarr's wanted (missing) albums, searches Soulseek through slskd, downloads the best match, moves the files into one folder per album under `/data/soulseek/downloads`, and asks Lidarr to import that folder. Runs as the media user, read-only. No web UI: the image's UI is turned off.

## URLs

None. It only talks to `media-lidarr:8686` and `media-slskd:5030` (`media-vpn:5030` with the slskd VPN).

## Depends on / used by

- Depends on: Lidarr and slskd, and the declarative layer for both API keys (an assertion enforces this).
- Used by: nothing. Lidarr shows the imports.

## Setup

### A) Without declarative

Not supported. Soularr reads both API keys from SOPS.

### B) With declarative

Automatic. The config is generated by Nix (`soularr/default.nix`): Lidarr and slskd hosts, `download_dir` `/data/soulseek/downloads` for both (all three containers see the same path), FLAC then MP3, missing albums only. The API keys are not in the file: Soularr expands `$LIDARR_API_KEY` and `$SLSKD_API_KEY` from an env file that sops-nix renders.

To change a setting, edit the `configFile` attribute set. Keys not set there keep Soularr's defaults. See the [example config](https://github.com/mrusse/soularr/blob/main/config.ini).

Manual: nothing. Add artists in Lidarr; their missing albums are searched on the next run.

## Troubleshooting

- Logs: `journalctl -u podman-media-soularr`.
- "No results" for an album: it is rare on Soulseek, or the release in Lidarr has an unusual track count. Lidarr › album › pick another release, or relax `[Release Settings]`.
- Downloads finish but Lidarr does not import: check Lidarr › Activity › Queue and `journalctl -u podman-media-lidarr`. Lidarr must see `/data/soulseek/downloads`.
- Failed imports are remembered in `/var/lib/media-server/soularr/failed_imports.json`, so they are not retried forever.

## Reset / backup

State: `/var/lib/media-server/soularr` (current page and failed import list). Nothing important.

To reset: `sudo systemctl stop podman-media-soularr`, delete the directory, `sudo systemctl start podman-media-soularr`.
